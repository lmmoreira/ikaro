Um serviço do tipo Turma não define recursos fixos como Agendamento (acima) — mas ainda declara, uma única vez aqui, quem/o que é elegível para cada posição (instrutor, sala, opcionalmente equipamento). Kit de Pedras Quentes

Nenhuma caixa marcada = modelo de hoje (o negócio inteiro é o recurso, ex. car wash). Uma caixa marcada = recurso único (ex. Corte + Escova, só Profissional). Duas ou mais marcadas = bundle — todas precisam estar livres na mesma janela ao mesmo tempo (CAND-07, CAND-31); ver a experiência do cliente em public-04-bundle-booking.html. Massagem Relaxante aqui marca as três — Profissional, Sala e Equipamento precisam estar livres juntos. Dentro de cada tipo marcado, a lista de elegíveis restringe o pool a um grupo específico de profissionais/salas/equipamentos, não qualquer recurso daquele tipo no tenant inteiro.
