Nenhuma caixa marcada = modelo de hoje (o negócio inteiro é o recurso, ex. car wash). Uma caixa marcada = recurso único (ex. Corte + Escova, só Profissional). Duas ou mais marcadas = bundle — todas precisam estar livres na mesma janela ao mesmo tempo (CAND-07, CAND-31); ver a experiência do cliente em public-04-bundle-booking.html. Dentro de cada tipo marcado, a checklist "elegível" restringe o pool a um subconjunto — resourcePoolIds no domínio (discovery §5) — em vez de qualquer recurso daquele tipo no tenant inteiro.
