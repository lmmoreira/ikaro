Discovery Prototype — Multi-Vertical Scheduling

Directional mockups for the scheduling model explored in MULTI_VERTICAL_SCHEDULING.md and MULTI_VERTICAL_SCHEDULING_USECASES.md. One fictional tenant, Vitta Studio, runs all three example verticals at once — Hair Styling (per-staff, customer-chosen appointment), Pilates (class, capacity 4), and CrossFit (class, capacity 20) — so a single resource (Camila Duarte) can show up as both a 1:1 hair stylist and a group Pilates instructor, the concrete instance of the "capacity as Service × Resource" finding (discovery §2, model #13).

Illustrative only. This is not a plan/journey/ prototype — no /docs-audit, no mandatory unhappy-path variants, no dev-notes handoff spec at that depth. One representative screen per concept, reusing the real --ba-* tokens and dashboard shell so it reads authentically, but built to answer "what direction are we heading," not to be implementation-ready.
Reviewed 2026-07-29 against the 31 candidate use cases: found and fixed a systemic actor mislabel (CAND-06–15 wrongly said MANAGER-only), two mislabeled CAND citations, and one missing use case (CAND-17b).
