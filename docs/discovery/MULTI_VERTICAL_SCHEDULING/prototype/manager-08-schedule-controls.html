O recurso sempre funciona dentro do horário do Vitta Studio.

Horário semanal

O negócio abre 08:00–20:00. Não é possível ampliar esse limite.

Exceção pontual

Mudanças alteram apenas disponibilidade futura. Aulas materializadas e atendimentos aprovados são compromissos: revise-os antes de salvar.

Turmas recorrentes

A confirmação lista sessões e reservas futuras afetadas. Períodos persistem como exceção para não serem gerados novamente.

Desativar recurso

Impede novos agendamentos. O sistema mostra compromissos futuros que precisam ser resolvidos; histórico nunca é removido.
