Lead Form — hotsite module

Illustrative prototype, discovery-stage. Full spec: ../lead-form-module.md. Not implementation-ready — see dev-notes.md for what's real vs. invented.

O que este protótipo valida:

Visitante — fluxo público

  • Teaser no hotsite
  • Formulário — visitante (guest)
  • Formulário — cliente logado (autopreenchido)

Gerente — configuração e leads

Reutiliza o shell real do editor de hotsite já existente (plan/journey/manager/prototypes/hotsite/) — mesmo drill-down "Configurar" que Hero/Chatbot já têm, e o mesmo sidebar/topbar, em vez de uma tela genérica inventada.

  • Aba Layout do editor — nova linha "Formulário de contato"
  • Configurar módulo — audiência, teaser e perguntas, tudo editado nesta mesma tela (cartões expansíveis, sem navegar para outra página)
  • Lista de leads (nova seção do menu)
  • Detalhe de um lead
  • Exportar CSV (mês/ano)
  • Configurar janela de retenção

Estados alternativos (unhappy paths)

Cobertura completa nos dois fluxos mais novos/arriscados (formulário público, construtor de perguntas). Demais telas cobrem apenas o estado alternativo mais relevante — ver dev-notes.md "Coverage scope".
