A decisão é única para o padrão inteiro. Uma vez aprovado, cada ocorrência semanal é confirmada automaticamente, sem nova revisão.

Recusar este pedido?

Nenhuma reserva foi criada, então não há nada a liberar. Ana é notificada; não há como desfazer. Ela pode enviar um novo pedido quando quiser.

Aprovar esta recorrência?

A partir de agora, as reservas semanais são geradas e confirmadas automaticamente — nenhuma revisão adicional é pedida por ocorrência. Reservas avulsas de outros clientes continuam passando por aprovação normalmente.

Sem uma decisão até 09:30, o pedido expira automaticamente e nenhuma reserva é criada — o mesmo prazo de 30 minutos usado para uma reserva avulsa desta sala.
