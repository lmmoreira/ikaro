Editor visual do hotsite

Uma proposta para editar o mesmo manifesto e os mesmos módulos atuais, mas vendo o resultado enquanto se muda cada opção.

1. Editor visual inline — fluxo completo Uma única tela: prévia viva à esquerda; action pane e bloco de campos contextuais à direita. 2. Editor visual inline — módulos e campos completos Hotsite completo e os campos reais de todos os 10 módulos, acessíveis pela página ou pela Estrutura. 2. Branding com mapa de impacto Cada cor explica onde é usada e destaca os elementos afetados na prévia. 3. Configuração por resultado Um módulo selecionado organiza opções em Conteúdo, Aparência e Avançado. 4. Layout: módulos, ordem e visibilidade O mesmo controle atual de ligar, desligar, ordenar e configurar módulos, no shell do Ikaro. 5. SEO e compartilhamento Os campos atuais, explicados pelo efeito que têm ao encontrar ou compartilhar o site. 6. Manifesto avançado A mesma rota de escape atual para editar o JSON completo, preservada para quem precisa dela. 7. Validação por tarefas As tarefas que um gerente deveria conseguir concluir sem precisar entender o modelo técnico.
