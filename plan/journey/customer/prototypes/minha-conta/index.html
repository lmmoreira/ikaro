Minhas Turmas — nova jornada (GAP)

Cobre o ciclo pós-inscrição: ver matrículas ativas, acompanhar fila de espera, pular sessões pontuais e cancelar a matrícula. Telas referenciadas como /my-account/turmas — rota ainda não existe no app.

  • Tela 6 — Minhas Turmas (lista de matrículas + fila de espera) GAP: /my-account/turmas · nova rota
  • Tela 7 — Detalhe da matrícula (turma fixa sem prazo) GAP: /my-account/turmas/[enrollmentId]
  • Tela 7b — Fila de espera (enrollment.status = WAITLIST) GAP: mesmo route, estado diferente · requer status WAITLIST no Enrollment
  • Tela 8 — Pular uma sessão específica (com motivo opcional) GAP: /my-account/turmas/[id]/pular · POST skip-session
  • Tela 8 (sucesso) — Sessão marcada como "Pulou" GAP: estado pós-confirmação · notifica fila automaticamente
  • Tela 8b — Cancelar matrícula (confirmação explícita) GAP: /my-account/turmas/[id]/cancelar · DELETE enrollment
  • Tela 7d — Detalhe pós-promoção (WAITLIST → ACTIVE) GAP: banner dismissível · enrollment.promotedAt < 24h · chegada via e-mail
  • Tela 8c — Erro ao pular sessão (rede/5xx) GAP: unhappy path · "Tentar novamente" re-habilita botão
  • Tela 8d — Erro ao cancelar matrícula (rede/5xx) GAP: unhappy path · checkbox resetado · "Tentar novamente"

O que este protótipo valida
  • As três seções (Próximos / Pendentes / Histórico) organizam bem os agendamentos?
  • O cartão de fidelidade (pontos ativos + data de expiração) é claro e bem posicionado?
  • Cancelar direto do card vs. entrar no detalhe e cancelar — qual fluxo é mais intuitivo?
  • O sheet de confirmação de cancelamento fornece contexto suficiente antes de confirmar?
  • O form de resposta ao admin (UC-005 A2) na tela INFO_SOLICITADO é compreensível?
  • O detalhe CONCLUÍDO mostra preço cotado vs. cobrado de forma legível?
  • A separação entre "Turmas" e "Agendamentos" como tabs distintas faz sentido para o cliente, ou gera confusão sobre onde procurar o quê?
  • O badge de posição na fila ("3ª na fila") na lista de turmas é suficiente, ou o cliente precisa de mais contexto logo ali?
  • "Pular sessão" é uma ação que o cliente vai entender sem explicação, ou precisa de um nome diferente?
  • A distinção entre "pular sessão" (pontual) e "cancelar matrícula" (permanente) está clara o suficiente nas telas — especialmente no detalhe?
  • O checkbox de confirmação explícita no cancelamento de matrícula é necessário, ou a página de confirmação já é suficiente como freio?
