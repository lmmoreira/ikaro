Como funciona

Todas as reservas do período são verificadas e criadas de uma vez, com todos os recursos do serviço, e o horário fica garantido até a data final. Você pode pular, reagendar ou encerrar a recorrência quando quiser.

Estado A2 · profissional + sala, os dois escolhidos pelo cliente
Profissional

Este profissional fica reservado toda semana.

Sala

Esta sala fica reservada toda semana.

Todos os requisitos são de escolha do cliente: um grupo para cada, na ordem do serviço. A política é FIXED_ASSIGNMENT e o pedido leva duas escolhas.

Estado C · falta escolher
Profissional

Escolha o profissional.

Cada grupo é obrigatório: o erro aparece sob o grupo que está sem escolha e o botão "Revisar" não avança.

Estado D · tudo automático (profissional e sala escolhidos pelo sistema)
Profissional
Escolhido automaticamente a cada semana, entre os profissionais livres
Sala
Escolhida automaticamente a cada semana, entre as salas livres

Se faltar profissional ou sala livre em alguma data, a recorrência inteira não é criada.

Nenhum requisito pede escolha do cliente: não há grupos, só linhas informativas, e nenhuma opção é buscada. A política é RESOLVE_PER_OCCURRENCE e o pedido não leva escolhas.

Estado E · profissional escolhido + equipamento de um conjunto de unidades
Profissional

Este profissional fica reservado toda semana.

Equipamento
Uma unidade livre é reservada a cada semana

Qualquer unidade do conjunto serve; o sistema escolhe.

Requisito AUTO_FUNGIBLE_POOL (qualquer unidade livre): informativo, como o automático, sem grupo.

Estado F · serviço antigo "local + profissional"
Profissional

Este profissional fica reservado toda semana.

O local do estabelecimento (requisito NONE, o mesmo para todo mundo) continua sendo conferido e reservado em cada data, mas não aparece no formulário nem na revisão: não há nada para escolher nem para informar.

Estado G · três requisitos (profissional, sala e equipamento)
Profissional

Este profissional fica reservado toda semana.

Sala

Esta sala fica reservada toda semana.

Equipamento
Uma unidade livre é reservada a cada semana

Não há limite de requisitos além de quantidade 1 em cada um: um grupo para cada requisito de escolha do cliente, uma linha para cada automático, na ordem do serviço.

Profissional (erro ao carregar)

Sala (sem opções)

Com um grupo sem opções, "Revisar" fica desativado: não há como montar o pedido.
