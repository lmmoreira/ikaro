Protótipo — CUSTOMER: Reservar Aula

Fluxo de inscrição em turma — drop-in (aula avulsa) e série de aulas.
Entrada: hotsite (cliente clicou em uma aula) ou "Novo → Reservar aula" na área do cliente.
Contexto sempre pré-definido: a aula já está selecionada antes do fluxo começar.

Entrada — catálogo de aulas

  • Tela 0 — Lista de aulas disponíveis no tenant GAP: /{slug}/aulas · GET /v1/class-types · entrada via "Novo → Reservar aula"
  • Tela 0c — Estado vazio (filtro "Com vagas" sem resultado) GAP — adicionada 2026-08-21, UX review: os 4 filter-tabs implicavam a possibilidade, nada estava desenhado para ela

Bifurcação (aula aceita drop-in e série)

  • Tela 0b — Escolha o tipo de reserva GAP: só aparece quando classType.allowsDropIn && classType.allowsSeries

Drop-in — Aula avulsa

  • Tela 1 — Escolha a sessão (com vagas disponíveis) GAP: GET /v1/class-types/:id/sessions
  • Tela 1b — Sessão lotada selecionada (vai para fila) GAP: estado alternativo — session.availableSpots = 0
  • Tela 2 — Confirmar reserva drop-in GAP: POST /v1/enrollments { type: DROP_IN, sessionId }

Série de aulas

  • Tela 2b — Montar a sequência (dias + horários + data de início) GAP: GET /v1/class-types/:id/recurring-slots
  • Tela 3 — Confirmar série GAP: POST /v1/enrollments { type: SERIES, slotIds, startsAt }

Estados de resultado

  • Tela 4 — Reserva confirmada (vaga garantida · ACTIVE) GAP: enrollment.status = ACTIVE
  • Tela 4b — Lista de espera (sessão lotada · WAITLIST) GAP: enrollment.status = WAITLIST
O que este protótipo valida
  • — A separação "Aula avulsa / Sequência de aulas" na tela 0 é clara sem precisar de explicação?
  • — A lista de sessões na tela 1 comunica disponibilidade de vagas de forma legível?
  • — "Entrar na lista de espera" na tela 1b está suficientemente distinto de "Reservar"?
  • — A tela 2b (montar série) está simples o suficiente ou parece complexa demais para o cliente?
  • — O resumo de confirmação (telas 2 e 3) dá segurança suficiente antes de confirmar?
  • — A tela de fila de espera (4b) define expectativa adequada sobre o que acontece a seguir?

Cenário de teste
Tenant: Vitta Studio · Aula: Pilates em Grupo · Instrutora: Camila Torres
Aceita: drop-in ✓ · série ✓ · 8 vagas por sessão · 50 min
