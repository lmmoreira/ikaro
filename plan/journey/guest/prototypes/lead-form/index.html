Estados alternativos (unhappy paths)

Cada tela abaixo é uma variante da mesma página, mostrando um estado de carregamento, erro ou sucesso. Nenhuma é uma rota nova.

  • Passo 1b — Carregando o catálogo de perguntas GAP
  • Passo 1c — Erro de validação (campo obrigatório/e-mail inválido) GAP — UC-039 A3/A4
  • Passo 1d — Verificação de segurança expirou GAP — UC-039 A1
  • Passo 1e — Limite de envios atingido (429) GAP — UC-039 A2
  • Passo 1h — Enviando (formulário bloqueado, aguardando resposta) GAP
  • Passo 1i — Erro genérico ao enviar (rede/5xx, não é um código conhecido) GAP
  • Passo 1f — Envio recebido com sucesso GAP
  • Passo 1g — Login exigido (audienceMode = CUSTOMER_ONLY) GAP — UC-040 A1
O que este protótipo valida:
✅ O formulário fica claro sobre quais campos são obrigatórios vs. opcionais?
✅ O erro de validação mostra o formulário completo, não só a seção com erro?
✅ O widget Turnstile se encaixa naturalmente no fluxo sem parecer um obstáculo extra?
✅ A tela de login exigido explica claramente por que o login é necessário e como voltar?
✅ Tokens de branding (--ba-*) são os mesmos que o hotsite usa?
